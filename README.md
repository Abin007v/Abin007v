### 🤖 What I build
I build **production AI agents**: LLM-powered assistants that talk to customers, call tools, and run business workflows on their own, with guardrails around them.

- 🧠 **Tool-calling agents** on OpenAI, Anthropic Claude and Google Gemini through the Vercel AI SDK
- 🔌 **Model Context Protocol (MCP)** to plug agents into external tools and data
- 📞 **Voice AI agents** that answer and place real phone calls (Twilio, ElevenLabs)
- 💬 **Omnichannel conversations**: the same agent across SMS, email and web chat
- ⚙️ **Agent workflows**: event triggers, timers and background jobs (BullMQ, Redis)
- 🛡️ **Guardrails**: human review of AI replies, tool-result leak guards, consent checks
- 🧾 **Structured extraction**: turning conversations into typed records with Zod schemas
- ⚡ **Real-time UIs** that update live as agents act (Socket.IO, React)
